# TTReferee public support site

Static privacy policy and support information for TTReferee iOS. Hosted using GitHub Pages from `main` / repository root. No app source or user recordings are stored in this repository.

- Support: https://weiyeplayer.github.io/ttreferee-support/
- Privacy policy: https://weiyeplayer.github.io/ttreferee-support/privacy.html
- Contact: GitHub Issues in this repository (public; do not attach personal footage).

Both pages include Simplified Chinese and English. No build dependencies, JavaScript, analytics or tracking.
